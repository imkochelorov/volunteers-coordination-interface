# Исследование прежнего бота: доступ заблокирован

Источник, указанный в задании: [Shemplo/volunteers-coordination-bot](https://github.com/Shemplo/volunteers-coordination-bot/). Старый репозиторий не изменялся и не является зависимостью нового приложения.

## Что удалось проверить

Были предприняты попытки получить репозиторий через Git, открыть его веб-страницу, получить README через raw GitHub и список файлов через GitHub API. Git завершился ошибкой `Could not resolve host: github.com`; веб-доступ к исходникам был отклонён средой. Доступного браузера для альтернативного чтения не оказалось.

Поиск подтвердил существование репозитория, но не предоставил содержимое файлов. **Ни один исходный файл не прочитан.** Поэтому нельзя достоверно описать прежние команды, модели, статусы, схему хранения, авторизацию, рассылку, обработку ошибок, тесты и развёртывание. Ссылки на предполагаемые файлы здесь намеренно отсутствуют.

## Что остаётся сделать

После восстановления доступа или получения архива исследовать только относящиеся к задаче части:

1. Команды и пользовательские сценарии организаторов, менеджеров и волонтёров.
2. Модели пользователей, групп, задач, статусов; создание задач и обработку ответов.
3. Рассылку, обновление ранее отправленных сообщений и ошибки доставки.
4. Хранение данных, авторизацию, тесты и инструкции запуска.

Для каждого вывода сохранить ссылку на реально прочитанный файл и ревизию. Полезные сценарии следует оценить на соответствие новому заданию; прежние технические ограничения можно называть только после чтения кода.

## Влияние на новую систему

Новая реализация построена по согласованным требованиям. Из старого решения не переносились код, протокол, данные, команды или зависимости. Общая серверная логика, транзакции, история, отдельные обсуждения, очередь Telegram-доставки и одноразовая привязка реализуются как требования новой системы; они не выдаются за обнаруженные свойства прежнего бота.

Это ограничение исследования не препятствует автономному запуску нового приложения, но пункт технического разбора прежних файлов остаётся незавершённым.
