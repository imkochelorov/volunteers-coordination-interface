# Проверка Kotlin-приложения

`./gradlew test` запускает интеграционные тесты на временных базах SQLite.
Тесты отправляют настоящие HTTP-запросы по loopback на автоматически назначенные порты.
Транспорт Bot API подменяется, чтобы проверить интеграцию без токена и доступа к Telegram.

Сценарии охватывают вход и выход, CSRF, проверку origin и повторы запросов,
отдельные очереди холлов, права на задачи, конкурентное принятие и восстановление данных
после перезапуска. Проверки Telegram охватывают приглашения, групповые назначения,
ошибки отправки до подключения волонтёров, принятие и завершение задачи, повторную обработку
события, вопросы с пересылкой и подтверждением, а также устаревшие кнопки после возврата задачи.

Для живой проверки выдайте тестовому волонтёру приглашение, назначьте задачу
и выполните цикл «Взять в работу» → «Готово». Проверьте обновление веба и карточек
в личном чате, затем создайте вопрос в боте и ответьте из веба.
